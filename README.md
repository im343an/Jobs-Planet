# Job Planet

**Job Planet** is a web application that provides dual functionalities for both **employers** and **employees**. It allows employers to post jobs according to their industry, track applications, and view the candidates. On the other hand, employees can browse and apply for jobs, have their CVs generated automatically, and keep track of the jobs they’ve applied to.

## 🚀 Features

### Employer Functionality:
- **Employer Registration**: Employers can create an account.
- **Job Posting**: Employers can post jobs based on their industry.
- **Job Management**: Employers can keep track of the jobs they've posted.
- **Candidate Tracking**: Employers can see which candidates have applied for the job.

### Employee Functionality:
- **Employee Registration**: Employees can register to create an account.
- **Job Browsing**: Employees can see all available jobs and filter by industry.
- **Automatic CV Generation**: Employees can input their information, and the software automatically generates their CV.
- **Job Applications**: Employees can apply to jobs and track their applications.

## 🛠 Tech Stack

- **Frontend**: Laravel Blade, HTML5, CSS3, Bootstrap
- **Backend**: Laravel
- **Database**: MySQL
- **Authentication**: Laravel Auth
- **File Uploads**: Laravel Storage
- **Deployment**: XAMPP / Hosting Server

## 📁 Folder Structure

- `app/` - Application logic
- `bootstrap/` - Bootstrap framework files
- `config/` - Configuration files
- `database/` - Migrations and seeds
- `public/` - Public files (images, CSS, JS)
- `resources/` - Views, assets, and lang files
- `routes/` - Web routes
- `storage/` - File uploads
- `tests/` - Test files
